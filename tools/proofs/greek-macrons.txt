## Capital upsilon with psili
# U+1F58/1F5A/1F5C/1F5E are unassigned in Unicode -- word-initial upsilon takes
# the rough breathing in Attic -- so these are the only capital-plus-breathing
# sequences with no precomposed character behind them.
Υ̓	# psili, bare
Υ̓́	# psili + oxia, bare
Υ̓̀	# psili + varia, bare
Ῡ̓́	# psili + oxia, macron
Ῠ̓	# psili, breve
Ὑ	# dasia, precomposed, for comparison

## Capital rho with psili
# U+1FEC is capital rho with dasia; the psili counterpart was never encoded,
# the same gap as capital upsilon. Lowercase has both (U+1FE4, U+1FE5).
Ρ̓	# psili
Ῥ	# dasia, precomposed, for comparison
ῤ	# lowercase psili, precomposed
